# Aser Trading — Angular Starter

Frontend starter for Aser Trading's public website and internal inventory/e-commerce dashboard.

## Brand
- Primary blue: `#3434C4` (approximation from supplied logo)
- Black: `#080808`
- White: `#FFFFFF`
- Accent pink: `#F20A72`
- Accent orange: `#F5A000`

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
npm install
npm start
```
Open `http://localhost:4200`.

## Build
```bash
npm run build
```

## Included
- Angular standalone components and routing
- Public landing page
- Internal dashboard shell
- Dashboard, inventory, products, transfers and orders pages
- Responsive layout and Aser brand styling
- Sample data only

## Important
This is a frontend starter with mock data. It is not connected to a backend, authentication provider, database, payment gateway or real inventory ledger. Before production, connect it to the secured Spring Boot API defined in the SRS, implement server-side authorization, and add automated tests.
